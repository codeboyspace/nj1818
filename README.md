# Airline Reservation & Flight Operations Management System

This repository now includes two runnable layouts:

- `arfoms1/` - existing integrated Spring MVC application.
- `microservices/` - new module-wise Spring Boot microservices split.

## Microservices modules
- `microservices/auth-service`
- `microservices/discovery-server`
- `microservices/config-server`
- `microservices/api-gateway`
- `microservices/flight-service`
- `microservices/booking-service`
- `microservices/checkin-service`
- `microservices/crew-service`
- `microservices/loyalty-service`

See `microservices/README.md` for endpoints and run steps.
